# v2-hub-admin-web · 任务与边界

> 负责人：@xiaoclux。管理侧前端：管理门户（登录 + 总览大盘）与管理端（左侧菜单，按 RBAC 权限显示）。开发端口 5173。规格：docs/05-详细设计-hub-admin-web.md、docs/03。

## 职责范围（这里做什么）

- 管理员登录（含 2FA）、总览大盘。
- 左侧菜单的管理功能：服务器、节点（入站与 Host 增删改查）、用户、套餐、链式代理策略、系统设置、审计日志。
- 菜单与按钮按后端返回的权限码显示 / 隐藏（后端仍做最终鉴权）。

## 接线约定（项目决议，违背即返工）

- 对外：生产域名 `HUB_ADMIN_DOMAIN`，静态文件在 MinIO 桶 `web-admin`，由 Caddy 分发（Ruling-6）。
- 依赖：只调 hub-server 的 `/api/admin/*`；类型与 client 由 `contract/hub-api.yaml` 生成，放 `src/api/generated/` 并入库（Ruling-1）。
- 同域部署，前端不配置后端地址；开发时由 Vite 代理到 127.0.0.1:8080。
- 会话 Cookie 由浏览器自动携带；非 GET 请求带 `X-CSRF-Token`。

## 边界（这里不做什么）

- 不 import `v2-hub-user-web` 的代码；需要相同组件时各写一份，或先在 docs 里提议抽公共包。
- 不直连 3x-ui 面板；所有面板操作都经 hub-server。
- 不在前端存储任何凭据（面板 token、用户密码），不用 localStorage 存会话。
