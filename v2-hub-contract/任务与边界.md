# v2-hub-contract · 任务与边界

> 负责人：全体（当前为 @xiaoclux 一人 + agent）。业务语义以 docs/03 为准。

## 职责范围（这里做什么）

- 契约文本：`hub-api.yaml`（OpenAPI 3.1）；表结构 `deploy/init.sql` + `deploy/migrations/`；上游 3x-ui API 快照 `upstream/3x-ui/`。
- 编排：开发中间件 `deploy/docker-compose.yml`；生产 `deploy/compose.deploy.yml` + `deploy/caddy/Caddyfile`；前端发布 `deploy/publish_web.sh`；生产部署 `deploy/deploy_prod.sh`（Ruling-62）。
- IT 联调脚本 `deploy/it/`；契约版本管理（git tag）。

## 接线约定（项目决议，违背即返工）

- 端口：hub-server 8080；admin-web 开发 5173；user-web 开发 5174；PostgreSQL 宿主机 15432；MinIO 宿主机 19000/19001；IT 用 3x-ui 12053/12054。
- 前端静态资源存 MinIO 桶 `web-admin` / `web-user`，Caddy 反代并做 SPA 回退；生产单域名，管理端在 `/admin/`（Ruling-6、Ruling-61）。
- 凭据只在 `deploy/.env`（`init_env.sh` 生成，不入库）。

## 边界（这里不做什么）

- 不含业务实现；不放生成物。
- IT 脚本只做黑盒（curl / psql / mc），不 import 模块代码；需要模块进程时脚本自起自停。
- 状态机、权限码含义、错误码含义属 docs/03，本目录只登记字段形状与枚举值。
