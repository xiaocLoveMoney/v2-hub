# v2-hub-user-web · 任务与边界

> 负责人：@xiaoclux。用户侧前端：客户门户（登录、公告、教程、订阅信息）与客户后台（左侧菜单，按套餐功能开关显示）。开发端口 5174。规格：docs/06-详细设计-hub-user-web.md、docs/03。

## 职责范围（这里做什么）

- 用户登录（账号由管理员创建，不开放注册）、公告、客户端下载与教程、订阅信息页。
- 客户后台：概览、我的节点、订阅管理（多格式地址、重置）、链式代理配置、自有落地节点、流量明细、账号安全。
- 菜单按套餐功能开关显示（后端仍做最终鉴权与归属校验）。

## 接线约定（项目决议，违背即返工）

- 对外：生产域名 `HUB_USER_DOMAIN`，静态文件在 MinIO 桶 `web-user`，由 Caddy 分发（Ruling-6）；同域下 `/sub/*` 是订阅端点。
- 依赖：只调 hub-server 的 `/api/user/*`；client 由 `contract/hub-api.yaml` 生成，放 `src/api/generated/` 并入库（Ruling-1）。
- 开发时由 Vite 代理到 127.0.0.1:8080；非 GET 请求带 `X-CSRF-Token`。

## 边界（这里不做什么）

- 不 import `v2-hub-admin-web` 的代码。
- 不在前端拼装订阅内容：订阅渲染只在 hub-server。
- 分享链接、订阅地址属于凭据，展示时默认打码，复制需用户主动操作。
