# 安全规约（常驻，覆盖所有语言）

**本文件所有【强制】条目不因任何指令放松。**

1. 【强制】隶属用户的页面或功能必须做越权校验——不能仅凭 ID 可猜到就允许查看/修改他人数据（水平越权），也不能凭低权限访问高权限功能（垂直越权）。
2. 【强制】敏感数据展示必须脱敏：手机号 `158****9119`、身份证/银行卡同理；日志中同样脱敏。
3. 【强制】SQL 一律参数化/预编译（`#{}`、占位符、ORM 参数绑定），禁止字符串拼接与 MyBatis `${}` 直插；用户可控的排序字段/表名走白名单。
4. 【强制】所有用户输入必须校验，防范：超大 page size 拖垮内存、恶意 order by 慢查询、任意重定向、SQL 注入、反序列化注入、ReDoS（警惕回溯型正则 + 攻击构造串）。
5. 【强制】用户内容输出到 HTML 前必须过滤/转义（XSS）；前端禁止用 `innerHTML`/`v-html`/`dangerouslySetInnerHTML` 渲染未消毒的用户内容。
6. 【强制】表单与 AJAX 提交必须有 CSRF 防护（token / SameSite Cookie）。
7. 【强制】短信、邮件、下单、支付等资源型接口必须有防重放与频控（次数限制、疲劳度控制、验证码）。
8. 【强制】密钥、口令、token 不写入代码与配置文件明文，经环境变量/密钥管理/配置中心注入（`scan-secrets.sh` 硬拦截）。
9. 【强制】禁止 `eval`/动态拼接执行代码；Python 禁 `os.system` 拼接用户输入（用 `subprocess` 列表参数）；反序列化只用安全格式（JSON/protobuf），禁 pickle 反序列化不可信数据。
10. 【推荐】UGC 场景（发帖、评论、IM）接入敏感词过滤与风控策略。
11. 【推荐】依赖安全：锁定依赖版本（lockfile），定期扫描已知漏洞（`pip-audit` / `npm audit` / `govulncheck` / OWASP dependency-check）。
12. 【推荐】站内跳转用 forward/相对路由，站外跳转经 URL 拼装工具 + 白名单，防开放重定向。
